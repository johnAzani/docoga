## 🏗️ TECHNICAL DECISIONS

### Architecture
- **Host:** GitHub Actions (free tier, 2000 minutes/month)
- **Content Generation:** 
  - Text: Python templates + free APIs (Hugging Face)
  - Images: Placeholder images (free, no AI needed initially)
  - Videos: FFmpeg slideshows (free)
- **Posting:**
  - Telegram: Telegram Bot API (100% free, no limits)
  - YouTube: YouTube Data API v3 (free tier)
  - Facebook: Graph API (free, requires Business Account)
  - Instagram: Graph API (free, requires Business Account)

### Free Tier Constraints
- GitHub Actions: 2000 free minutes/month
- YouTube API: 10,000 units/day (~6 uploads/day)
- Telegram: Unlimited
- Facebook/Instagram: Free but requires approval

### DocOga-Specific Context
- **Product:** Document generation for Nigerian landlords/tenants
- **Tools:** Tenancy Agreement, Rent Receipt, Invoice, etc.
- **Business Model:** Free with watermark, ₦2,000 Oga Pass for clean docs
- **Current Automation:** Payment webhooks (Flutterwave, Selar, Paystack)
