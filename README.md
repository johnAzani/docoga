# DocOga 🇳🇬 — The Oga of Documents

Free tenancy agreement, notice to quit, rent receipt and invoice generator
for Nigeria. Single-file static app — no build step, no server, 0 Naira/month to run.

## Structure
- `site/` — the website (the ONLY folder that is deployed publicly)
  - `index.html` — the entire app: 9 document tools + Oga Pass payment system
  - `success.html` — instant pass-delivery page (payment redirect target)
  - `<tool>-<state>.html` × 24 — state SEO pages (4 tools × 6 states),
    generated by `tools/gen_state_pages.py`
  - `*-nigeria.html` × 7 — national guide pages (the PLAN.md §4 keyword
    cluster), generated by `tools/gen_guide_pages.py`
  - `privacy.html`, `terms.html`, `robots.txt`, `sitemap.xml`
  - `admin.html` — the **owner dashboard** (public file, inert without the
    passphrase; unlisted, noindexed, `Disallow: /admin`, CSP `frame-ancestors
    'none'` via `site/_headers`). Handbook: `ADMIN_DASHBOARD.md`
- `worker/` — Cloudflare Worker for automatic pass-code delivery
  (deploy to Cloudflare Workers — NOT to the website)
- `tools/` — QA gate, test suites and page generators (`npm run qa`, `npm test`)
- `mobile/` — the Android app: a Capacitor shell around `/admin`, built to a
  sideloadable APK by CI (`ADMIN_DASHBOARD.md` §7, `mobile/README.md`)

## Deploy (Cloudflare Pages)
Hosted on **Cloudflare Pages**, connected to this repository — every push to
`main` deploys automatically. See `GITHUB-CLOUDFLARE.md` for the full setup.

| Setting | Value |
|---|---|
| Production branch | `main` |
| Build command | *(none — no build step)* |
| Build output directory | **`site`** — never blank, never `/` |

> **`site` is a security setting.** Cloudflare publishes only what that field
> names. Left blank it would publish the repo root: `PLAN.md`, `AUTOMATE.md`,
> `DOCOGA-RISK-LOG.md`, `worker/`, and `unlock-codes.txt`.

Netlify is **no longer used** — `netlify.toml` was removed 3 Oct 2026 and the
Netlify GitHub App should be disconnected (see `GITHUB-CLOUDFLARE.md` Step 4).

## Configuration
Edit the CONFIG block at the top of the `<script>` in `site/index.html`
(`PAYMENT_URL`, `SUPPORT_WHATSAPP`, `SITE_URL`, `WORKER_URL`, `ANALYTICS_ID`)
and `WORKER_URL` in `site/success.html`.

## Owner dashboard
`https://docoga.com.ng/admin` — revenue, passes, expiring-soon list, Business
teams, leads, hand-minting and session control, one page, ₦0. `worker/index.js`
serves 12 `/admin/*` routes off the same KV namespace; the daily cron builds the
rollup so no page load ever scans the keyspace. Two Cloudflare **secrets** switch
it on (`ADMIN_PASSPHRASE`, `ADMIN_AUTH_SECRET`); with either missing the API
answers `503 admin_disabled` and the page is a locked door.
→ **`ADMIN_DASHBOARD.md`** (setup, what each number is worth, the sync law)

## Security — read this
- `unlock-codes.txt` is **gitignored** — it is paid-product inventory. NEVER commit it.
- Payment-provider secret keys live ONLY in Cloudflare Worker secrets. Never in this repo.
- The dashboard passphrase and its session HMAC key are the same rule:
  `wrangler secret put` only, never in `site/admin.html`, `mobile/`, or git —
  which is also why the dashboard page and the APK are safe to publish at all.
- The Android signing key lives in CI secrets (`DOCOGA_APK_KEYSTORE_B64`), never
  in the tree (`mobile/.gitignore` refuses `*.jks` for the same reason).
- Keep this repository **PRIVATE**.
