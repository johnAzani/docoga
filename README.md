# DocOga 🇳🇬 — The Oga of Documents

Free Nigerian tools for tenancy agreements, notices to quit, rent receipts,
invoices, employment contracts, caution receipts, demand letters, payslips,
warning letters and Powers of Attorney. Single-file static app — no build step,
no server, 0 Naira/month to run.

## Structure
- `site/` — the website (the ONLY folder that is deployed publicly)
  - `index.html` — the entire app: 10 document tools + Oga Pass payment system
  - `success.html` — instant pass-delivery page (payment redirect target)
  - `<tool>-<state>.html` × 48 — state SEO pages (4 tools × 12 states),
    generated by `tools/gen_state_pages.py`
  - `*-nigeria.html` × 7 — national guide pages (the PLAN.md §4 keyword
    cluster), generated by `tools/gen_guide_pages.py`
  - `privacy.html`, `terms.html`, `robots.txt`, `sitemap.xml`
  - `admin.html` — the **owner dashboard** (public file, inert without the
    passphrase; unlisted, noindexed, `Disallow: /admin`, CSP `frame-ancestors
    'none'` via `site/_headers`). Handbook: `ADMIN_DASHBOARD.md`
- `worker/` — Cloudflare Worker for automatic pass-code delivery
  (deploy to Cloudflare Workers — NOT to the website)
- `tools/` — QA gate, test suites and page generators (`npm run qa`, `npm test`)
- social automation — `facebook_autopost.yml` posts the daily copy to the DocOga Page
  and renders a Reel on Mondays + Thursdays; `telegram_autopost.yml` and
  `youtube_scheduled.yml` carry the other two lanes (₦0; GitHub Actions is the cron).
  **A `schedule:` in a workflow file is a claim, not a fact** — GitHub only runs
  schedules from the default branch, and a lane can sit red for a week without anyone
  looking. `automation-heartbeat.yml` (daily) reads every `cron:` in
  `.github/workflows/`, compares *age since last success* against each lane's own
  cadence, prints a summary table of all of them, and files one labelled issue naming
  the lane and the secrets to check. Handbook, token minting, failure matrix, the
  Reels three-phase protocol and what is deliberately *not* automated:
  **`FACEBOOK_AUTOMATION.md`**. Telegram: `TELEGRAM_AUTOMATION.md`.
- Instagram + Threads (the two Meta lanes, incl. the token vault and the Standard-Access
  correction): **`INSTAGRAM_THREADS_AUTOMATION.md`**.
  Run the heartbeat by hand any time:
  `python3 tools/automation_heartbeat.py --repo <owner>/<repo> --token "$(gh auth token)" --verbose`
- `brain/` — **the standing editor** (16 Oct 2026). `brain.yml` runs nightly, reads the
  business memory + editorial policy + the section-cited law shelf, asks Gemini (free
  tier, 2–3 requests) for the next days' posts, Short topics and visual briefs, and
  publishes a pack only after citation, verification, brand, repetition and shape gates.
  Lanes read `brain/drafts/`; with no pack they post the hand-written rotation. Sundays
  it drafts the next Deep-Dive episode. It is held to a plan (`brain/strategy.md`,
  `brain/audience.md`, `brain/goals.json`): every Monday `brain_scorecard.yml` grades
  followers, sends, replies, hours and — with the `DOCOGA_ADMIN_PASSPHRASE` secret — pass
  sales against the goals, learns which hooks and readers actually earned, keeps the one
  "📊 Weekly scorecard" issue current, and writes the week's orders into the brain.
  `brain_replies.yml` answers every real comment on Threads, Instagram and Facebook within
  ~90 minutes of each post, from the post's own cited facts, with a deep link to the exact
  tool page. Handbook: **`docs/BRAIN.md`**. Kill switch: variable `DOCOGA_BRAIN=off`.
  Reach layer (17 Oct): a dated newsdesk the brain quotes, Threads topic tags + polls +
  cross-share to Instagram, Instagram Trial Reels, a Tuesday Telegram quiz, a **LinkedIn
  lane** (`docs/LINKEDIN_AUTOMATION.md`, Mon/Wed/Fri) and **TikTok inbox drafts** riding the
  Shorts lane (`docs/TIKTOK_AUTOMATION.md`) — both dormant until their secrets exist.
- `mobile/` — the Android app: a Capacitor shell around `/admin`, built to a
  sideloadable APK by CI (`ADMIN_DASHBOARD.md` §7, `mobile/README.md`)

## Deploy (Cloudflare Pages)
Hosted on **Cloudflare Pages**, connected to this repository — every push to
`main` deploys automatically. See `GITHUB-CLOUDFLARE.md` for the full setup.

| Setting | Value |
|---|---|
| Production branch | `main` |
| Build command | *(none — no build step)* |
| Build output directory | **`site`** — never blank, never `/` |

> **`site` is a security setting.** Cloudflare publishes only what that field
> names. Left blank it would publish the repo root: `PLAN.md`, `AUTOMATE.md`,
> `DOCOGA-RISK-LOG.md`, `worker/`, and `unlock-codes.txt`.

Netlify is **no longer used** — `netlify.toml` was removed 3 Oct 2026 and the
Netlify GitHub App should be disconnected (see `GITHUB-CLOUDFLARE.md` Step 4).

## Configuration
Edit the CONFIG block at the top of the `<script>` in `site/index.html`
(`PAYMENT_URL`, `SUPPORT_WHATSAPP`, `SITE_URL`, `WORKER_URL`) and `WORKER_URL`
in `site/success.html`. Analytics is deliberately release-gated in
`site/analytics-consent.js`; do not paste a GA measurement ID into the app or
open that gate until the privacy/transfer checklist in `docs/ANALYTICS_SETUP.md`
is complete.

## Owner dashboard
`https://docoga.com.ng/admin` — revenue, passes, expiring-soon list, Business
teams, leads, hand-minting and session control, one page, ₦0. `worker/index.js`
serves 12 `/admin/*` routes off the same KV namespace; the daily cron builds the
rollup so no page load ever scans the keyspace. Two Cloudflare **secrets** switch
it on (`ADMIN_PASSPHRASE`, `ADMIN_AUTH_SECRET`); with either missing the API
answers `503 admin_disabled` and the page is a locked door.
→ **`ADMIN_DASHBOARD.md`** (setup, what each number is worth, the sync law)

## Security — read this
- `unlock-codes.txt` is **gitignored** — it is paid-product inventory. NEVER commit it.
- Payment-provider secret keys live ONLY in Cloudflare Worker secrets. Never in this repo.
- The dashboard passphrase and its session HMAC key are the same rule:
  `wrangler secret put` only, never in `site/admin.html`, `mobile/`, or git —
  which is also why the dashboard page and the APK are safe to publish at all.
- The Android signing key lives in CI secrets (`DOCOGA_APK_KEYSTORE_B64`), never
  in the tree (`mobile/.gitignore` refuses `*.jks` for the same reason).
- Keep this repository **PRIVATE**.
